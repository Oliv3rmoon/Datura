**Nightshade Stream v1.001.000: the first Nightshade Stream, based on ProsperoLight 01.000.110.** Nightshade Stream is Oliv3rmoon's release of ProsperoLight by BlackBearReloaded, a port of Moonlight: ProsperoLight 01.000.110 with a new name, Nightshade's look and updates from this repository.

## What changed

- **The name.** The PS5 home screen, the header, the About page, the update dialog, the stream's notifications and the on-screen keyboard say Nightshade Stream, in all 31 languages. The About page keeps the Moonlight, Sunshine and ProsperoLight credits.
- **The look.** Nightshade's black and red: near-black pages, black glass panels, a red accent for the main actions, the focus and the connecting bar, and a near-black sky with a low red glow.
- **The art.** The nightshade flower with the stream going out of it as the mark, and a new icon (a black controller lit red, the flower on its touchpad), home background and launch picture, drawn in Nightshade's style.
- **Updates from this repository.** The app asks [Oliv3rmoon/Nightshade-Stream](https://github.com/Oliv3rmoon/Nightshade-Stream/releases) for a newer release that is not a pre-release and installs it with **Update now**, after checking `PPSA99002.zip` against `SHA256SUMS`. It never offers ProsperoLight's own releases.
- **What stays.** The title ID (PPSA99002) and `/data/prosperolight`, so it installs over ProsperoLight and keeps your PCs, pairing and settings. Streaming is ProsperoLight 01.000.110's, built with the same measured settings.

Built and checked by the host tests; not yet run on a console.

## Install

- `PPSA99002.zip`: close ProsperoLight, extract the ZIP and copy its `PPSA99002` folder over your current one (`/data/homebrew/PPSA99002`). ProsperoLight doesn't offer this release itself, so this one is copied by hand; from it on, **Update now** applies the next one. The new icon and pictures appear once the title is registered again.
- `SHA256SUMS`: the checksum of the download. `gh attestation verify PPSA99002.zip -R Oliv3rmoon/Nightshade-Stream` checks that this repository's workflow built it.
- To go back, copy an official [ProsperoLight release](https://github.com/blackbearreloaded/ProsperoLight/releases) over it the same way.
