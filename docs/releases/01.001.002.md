**Datura v1.001.002: the community in About.** Where to find other Datura players, from the app.

## What changed

- **The community in About.** About now names the community's Discord server, **nightly**, with its address (`discord.gg/pSqgRU3YP9`) and a QR code your phone opens it with; **Cross** there shows the code larger. The first time Datura starts with this version, a card shows the same once, after any update offer; any button closes it, and it doesn't come back. In all 31 languages.
- **Streaming is as it was**, built with the same measured settings as 01.001.001.

## Install

- `PPSA99002.zip`: choose **Update now** when Datura offers this release, or close the app, extract the ZIP and copy its `PPSA99002` folder over your current one (`/data/homebrew/PPSA99002`). Your PCs, pairing and settings stay.
- `SHA256SUMS`: the checksum of the download. `gh attestation verify PPSA99002.zip -R Oliv3rmoon/Datura` checks that this repository's workflow built it.
